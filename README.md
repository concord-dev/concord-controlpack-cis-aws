# concord-controlpack-cis-aws

CIS AWS Foundations control pack for [Concord](https://github.com/concord-dev/concord).

## Install

```sh
concord controlpack install ghcr.io/concord-dev/concord-controlpack-cis-aws:v0.1.0
```
